# BudgetNest 💰

BudgetNest is a multi-user personal finance and budget tracking application designed to help users understand where their money goes and manage monthly spending.

## ✨ Planned Features

- 📊 Personal finance dashboard
- 💸 Income and expense tracking
- 🎯 Monthly budget management
- 🚨 Budget limit and overspending alerts
- 📈 Spending reports and insights
- 🌍 Multi-currency support
- 👥 Secure multi-user accounts
- 🔐 Authentication and private financial data

## 🛠 Tech Stack

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express

### Database
- PostgreSQL
- Docker for local development

## 🚧 Current Status

BudgetNest is currently under active development.

- ✅ Day 1 — React dashboard UI
- ✅ Day 2 — Express API & PostgreSQL foundation
- ⏳ Day 3 — Authentication & multi-user accounts
- ⏳ Transactions
- ⏳ Budget management & alerts
- ⏳ Reports & insights
- ⏳ Cloud deployment

## 🗄 Database

The initial database schema includes:

- `users`
- `transactions`
- `budgets`

Each user's financial data will be isolated using user-specific ownership.

## 🎯 Goal

Build a simple finance tracker that can be used by people in different countries, including Japan and Bangladesh, with support for different currencies.
